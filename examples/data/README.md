# Iris Dataset

`iris.csv` contains 150 observations with four numeric measurements and one
species label. It has no header row; the columns are sepal length, sepal width,
petal length, petal width, and class.

The data are the Iris dataset introduced by R. A. Fisher and distributed by
the [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/53/iris),
DOI [`10.24432/C56C76`](https://doi.org/10.24432/C56C76). UCI publishes the
dataset under the
[Creative Commons Attribution 4.0 International license](https://creativecommons.org/licenses/by/4.0/).

This CSV is byte-identical to `test/data/iris.csv` from
[DecisionTree.jl v0.12.3](https://github.com/JuliaAI/DecisionTree.jl/tree/v0.12.3).
Its SHA-256 digest is
`6f608b71a7317216319b4d27b4d9bc84e6abd734eda7872b71a458569e2656c0`.
The dataset attribution and license are separate from the MIT license covering
MHABR.jl source code.
